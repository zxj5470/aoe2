## 严重缺陷

### 1. BuildingPlacementSystem 缺少 CHURCH 建筑配置

**位置**: `src/systems/BuildingPlacementSystem.js:17-117`

**问题**: `buildingTypes` 对象定义了 11 种建筑配置（HOUSE ~ CASTLE），但缺少 `CHURCH`。ActionPanel 的 default preset (`src/ui/ActionPanel.js:45`) 包含教堂按钮，点击后调用 `togglePlacement(BUILDING_TYPES.CHURCH)` → `buildingTypes['church']` 为 `undefined` → 输出 warn 但不启动放置。

**复现步骤**: 选中村民 → 点击教堂按钮 → 无放置预览出现

**修复方向**: 在 `buildingTypes` 中添加 `[BUILDING_TYPES.CHURCH]` 配置（width:3, depth:4, height:4, cost: { wood: 175, gold: 100 }, health: 600）

---

### 2. Game.getBuildingWidth/Depth/Height 缺少 TOWN_CENTER 条目

**位置**: `src/core/Game.js:291-344`

**问题**: 三个尺寸查询方法中，所有建筑类型都用了 `[BUILDING_TYPES.*]` 计算属性键，但全部遗漏了 `[BUILDING_TYPES.TOWN_CENTER]`。调用这些方法查询城镇中心会返回 fallback 值 `2`，而城镇中心实际尺寸是 4x4。

```javascript
// Game.js:291-305 - 缺少 TOWN_CENTER
const widths = {
    [BUILDING_TYPES.HOUSE]: 2,
    [BUILDING_TYPES.FARM]: 3,
    // ... 11 种建筑
    [BUILDING_TYPES.WATCH_TOWER]: 2
    // 缺少: [BUILDING_TYPES.TOWN_CENTER]: 4
};
return widths[normalizedType] || 2;  // town_center 返回 2（错误）
```

**当前影响**: 城镇中心总是硬编码创建（`EntityManager.initTownCenter`, `spawnTownCenters`），暂未触发此 bug。但未来通过 BuildingPlacementSystem 放置或尺寸查询会出错。

**修复方向**: 三个对象各补充 `[BUILDING_TYPES.TOWN_CENTER]: 4`

---

### 3. BuildingBase.getAppearanceConfig 缺少 height 字段

**位置**: `src/entities/BuildingBase.js:96-192`

**问题**: `getAppearanceConfig()` 定义了各建筑的 width/depth/symbol/color/bgColor，但未定义 height。建筑高度依赖外部 `config.height` 传入。而 `Game.getBuildingHeight` 和 `BuildingPlacementSystem.buildingTypes` 都各自维护了一套 height 值，形成三处分散定义。

**风险**: 未来修改建筑高度需要在 3 个地方同步，容易遗漏。

**修复方向**: 在 `getAppearanceConfig` 中统一定义 height，其他位置从此读取。

### 5. BuildingCollision 两个方法坐标系不一致

**位置**: `src/entities/BuildingCollision.js:96-132` vs `195-222`

**问题**:
- `getOccupiedGridCells(cellSize)` — 使用 `MAP_CONFIG.width/height` 偏移，将世界坐标映射到地图网格坐标（0 ~ MAP_CONFIG.width）
- `getOccupiedCells()` — 直接用 `CELL_SIZE` 做整数除法，无 MAP_CONFIG 偏移

`EntityManager.invalidatePathCacheForEntity` 使用 `getOccupiedGridCells`，而 `getOccupiedCells` 也被暴露在 `Building` 公共接口上。如果调用方误用 `getOccupiedCells`，网格坐标将偏移半个地图宽度，导致寻路缓存失效错误位置。

**修复方向**: 标记 `getOccupiedCells` 为 deprecated，统一使用 `getOccupiedGridCells`。
